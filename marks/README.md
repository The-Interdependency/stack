# Interdependency repo marks

Family lives here. Each other repo should hold only `docs/icon.svg`.

Field is taken from interdependentway.org: navy ground, concentric unit circle, cardinal ticks. Status is in the outer ring — solid live, dashed archived/emerging, warm dotted fork.

This folder is identity, not authority. It transfers no proof, measurement, or semantic status.

## Paths

- `marks/svg/<repo>.svg` — source marks
- `docs/icon.svg` — this repo's own mark (stack)
- `marks/manifest.json` — ids, roles, status, palette
- `marks/generate_icons.py` — regenerate

`org` is the organization mark. `epac` has no source repo yet; the mark exists because stack already names it. Termux forks are off-palette on purpose.
