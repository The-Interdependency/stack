# English ordinal construction — replacement profile

Operator request: radial distance is repeated halving by occurrence ordinal;
angle is defined by the newly expanded public gonol. This selected replacement profile constructs
that law instead of reinterpreting the previous orthogonal or overlap metrics.

## Public gonol

Admission is the exact union of all scalars admitted by the complete pinned
OEWN structural field, all inherited Public Gonol scalars, Unicode 18.0.0
numeric categories Nd/Nl/No, its derived Math property, and the explicit logical
supplement in `ordinal_construct.py`. No normalization, case folding, surrogate
positions, prime padding, missing-scalar fallback, or inferred operator meaning.

The new layout keeps SPACE first and the inherited 157 anchors in their
relative cyclic order. Additional scalars, sorted by code point, are distributed
as evenly as possible after those anchors. Every resulting position i has the
exact angle i/N turns. The actual N comes from the union, not an estimated count.
This balanced insertion is an explicit engineering profile choice. It is not
claimed to recover a hidden algorithm behind the old fixed arrangement.

Closed words use a second explicit carrier ordered lexicographically by their
sequences of new public-gonol indexes. That ordering is likewise a declared
profile choice, not a semantic ranking or a last-glyph angle. The UCNS constructor
accepts any explicitly declared carrier for further recursive scales.

## Geometry and recovery

For zero-based occurrence i among n participants, radius = R/2**(n-i).
The newest participant is at R/2; an append halves previous radii without
changing their carrier angles. Each closed word retains its full ordered glyph
interior. A higher construction contains references to those actual closed
interiors, with repeated occurrences, whitespace, punctuation and original
source relations intact.

The initial equidistant field and the angular placement are distinct stages.
Arbitrary circular placement is not an isometry of a high-dimensional simplex.
SPACE's scalar angle is zero; the local frame center is the radial reference.
A SPACE occurrence is not silently placed at radius zero or discarded.

## Artifact

`build` creates a new directory only:

- `admission/`: exact verified corpus, raw source evidence, ordered words,
  components, definition origins and provenance. This is constitutive material,
  not an optional cache. Its old carrier positions are historical admission
  metadata and never supply the replacement's angles.
- `public-gonol.json`, `word-carrier.json`: complete exact angular registries.
- `geometry.db`: every closed word/source frame and its ordinal placements,
  linked to the retained interiors and source records.
- `ucd/`: the exact property input bytes and manifest-bound hashes.
- `manifest.json`, `verification.json`: new profile identity and independent
  all-placement replay; neither is a substitute for the construction itself.

The hosted workflow also retains source licenses, an exact angular TSV, query
output and resource receipts. It writes no repository files and does not merge.
Old structural receipts are never presented as receipts for this geometry.
The source work graph is CI provenance, retained separately as
`source-work-graph.json` in the evidence archive and bound to the selected source
commit by CI. It is not packaged as construction data or covered by the artifact
verifier's `SURVIVED` result. The construction verifier covers its declared
manifest, carrier registries, Unicode inputs, source admission and geometry;
auxiliary licensing text is not a geometry or authority claim.

## Execute

Use the exact UCNS commit in `ordinal-work-graph.json`. Install its locked test
extra and PyYAML 6.0.2. The existing structural parser remains separately pinned;
expanding the public scalar registry does not silently change its segmentation.

```bash
export PYTHONPATH=research/english-gonol
python -m english_gonol.structural_construct build \
  --source-root /path/to/pinned-oewn/src/yaml \
  --ucns-source-root /path/to/pinned-admission-carrier \
  --out-dir /path/to/new-admission
python -m english_gonol build \
  /path/to/new-admission /path/to/unicode-18-ucd /path/to/new-geometry
python -m english_gonol verify /path/to/new-geometry
python -m english_gonol query /path/to/new-geometry 'the geometry'
```

Full corpus means the source verifier has replayed the exact 73-file OEWN tree
and every source record. The new independent checker additionally recomputes all
local exponents, angles, references and closure receipts without calling the
producer's placement function. Missing, added or altered rows fail. A fixture
Unicode file or unit-test success alone is not complete-corpus evidence.

## File plan and resources

`english_gonol/ordinal_construct.py` owns admission expansion, composition and
artifact verification; UCNS owns the geometric law. `tests/test_ordinal_construct.py`
owns fixture/property regressions. The workflow owns explicit input acquisition
and full replay. `ordinal-work-graph.json` binds input ownership and exact source
states. The supported entrypoint and retirement are declared in `../ACTIVE_CONSTRUCTION.json`.
The root research-participant manifest and English BASE explicitly record the
selected source and inputs. Canonical release pins, UCHC graduation and the website
remain unchanged. The construction source commit is recorded by hosted evidence, avoiding a
self-referential committed head hash.

Expected working footprint is below 4 GiB; the hosted runner checks free disk
before work. The source has 46,372,711 raw YAML bytes. No artificial science
stopping time is introduced; the workflow uses the platform's job boundary.
The local environment cannot fetch the complete public source/UCD bytes, so
full construction is executed by the repository workflow rather than calling a
small local fixture the full construct.
