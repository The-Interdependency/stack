# Piccirillo Conway Trace Transfer — Research Note v0

## Standing
Stack-local research note. Not UCNS canon. Not UCHC construction. Records an external topological result for geometry and property-transfer research.

## Source
Lisa Piccirillo (2018, published 2020): the Conway knot is not smoothly slice. Proof constructs a trace-equivalent sibling knot on which Rasmussen’s s-invariant is nonzero, forcing the shared non-sliceness conclusion. Completes smooth-sliceness classification for knots with fewer than 13 crossings.

## Relevance to UCNS
UCNS already admits prime-indexed ribbon, link, interval, Milnor, and Alexander topological geometry. The result supplies a concrete 4-dimensional example of trace equivalence: knots sharing a smoothly equivalent trace share smooth-sliceness status. An existing invariant detects the obstruction on the sibling but not directly on the original. Distinguishes smooth from topological slice.

## Relevance to UCHC
Recursive attachment and shared-identity constructions preserve a determining structure while altering the local object enough for an existing test to fire. Trace sibling is a candidate pattern for property-preserving relation that enables detection without direct computation on the original object.
