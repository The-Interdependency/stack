# Based-traversal provenance history audit v0

**Standing:** stack-local committed-history provenance obstruction audit.
Not UCNS canon, not a traversal constructor, and not an arithmetic readout.

## Question

The predecessor audit stopped because a based recursive traversal requires five
geometric certificate fields:

1. origin attachment;
2. directed tangent or chirality;
3. rotation system;
4. marked outgoing dart;
5. closure rule.

This audit asks the smallest next question: does current UCNS authority, its
reachable local history, or the exact A0 source provenance already define any
of those fields for the recursive Public Gonol relation groupoid?

No field is inferred from carrier order, caller order, source order, an API
default, a construction ordinal, an id, or a hash.

Twenty-one high-signal artifacts were bound to exact commits, trees, blobs,
and SHA-256 content digests. They establish useful local structure, but none
fills a recursive traversal certificate field:

| Candidate | What exists | Why it does not qualify |
|---|---|---|
| Pinned Public Gonol | exact position-zero carrier origin | no origin-to-recursive-groupoid attachment |
| Pinned direct Mobius | position zero, two frames, signed motion, local two-turn return | sign is caller supplied; full-gonol attachment is explicitly unresolved |

| P5/P7 link experiments | fixed link basepoints and marked meridian/longitude data | no map from those prime-link marks to Public Gonol return generators |

| Branch-only lexical recursion | source/lexical composition candidates | not in pinned ancestry and excluded by the geometry-only authority boundary |

The geometry-only purge is load-bearing: historical existence is a recovery
lead, not current authority. A historical candidate would still need a clean,
intrinsic geometric definition and explicit promotion.
