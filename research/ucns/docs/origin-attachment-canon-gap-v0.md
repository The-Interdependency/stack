## Required canon axiom

The smallest missing relation is an authority-owned, unoriented geometric
incidence

```text
iota: {O} -> V(T),  iota(O) = v0
```

where `O` is the exact Public Gonol or Structural Null origin, `T` is a
canon-defined traversable recursive structure, `V(T)` is its object set, and
`v0` is one unframed base object. The axiom must identify `v0` intrinsically
and replayably. If Public Gonol position zero and Structural Null are intended
to be the same source, their identification must also be explicit. If the
native visible phase-zero class is intended, canon must bind that class into
`T` explicitly.

The receipt must minimally bind authority, UCNS commit, operation identity,
source origin, target structure and object, relation kind, input geometry
digest, and independent replay digest.

The axiom must not select direction/chirality, a rotation system, an outgoing
dart, or closure. Those remain later dependencies.
