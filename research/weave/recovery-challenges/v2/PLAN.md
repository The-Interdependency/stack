FROM: v1 covers one repeated native sequence-cycle shape. The user reports an
external recovery of all eight records; that report is not independently replayed
here. Current source still does not implement the complete specified private

API refusal are not confidentiality results. Known literal leakage stays visible.

## Coverage rule

The byte-composable alphabet is N (actual corpus normalization), A (actual native
sequence affixiation and eight-circle placement), U (literal numeral packet),
S (prime-route section interleave), W (whole-stream last/first), B (per-byte bit
reflection from the prior representation experiment). For these six operations:

- Every singleton at one, two and three repetitions.
- Every word over every distinct pair with each count from one through three:
  all 62 orderings per pair, including alternating and separated repetitions.
- Every subset of three or more operations in forward and reverse canonical order.
- Each full six-operation order, forward and reverse, with each operation inserted
  at every gap until its count is two or three; also all six repeated twice/thrice.

Deduplicate identical schedules and publish the resulting counts. This is exhaustive
pair ordering/count coverage plus declared higher-order coverage, not exhaustive
enumeration of all six-symbol words. Every primitive count is at most three.

Additional families cover exact three-byte-record reversal R with B/S/W, typed
legacy split/corpus/interleave/join/whole candidates, and unchanged WVC cycle
records with one through three rounds. R refuses nonmultiples of three; split/join
preserve lane types. Historical transport and representation candidates keep their
own scope. They cannot satisfy native private-gonol obligations.

Component witnesses independently exercise sequence discovery, literal and recipe
numerals, base-2/base-10 spans, prime-index recursion, all eight native circles,
normalization, typed lanes, and cancellation/commutation. Missing whole-message
gonol, private binding, asymmetric KeyGen, complementary cryptographic thread law,
authentication and replay state remain explicit unmet obligations. The twin-ray
public face is checked as a lossy carrier, never passed off as a recoverable cipher.

Private operator artifacts live outside the checkout and are delivered separately.
Network boundaries are source acquisition and artifact publication only. The
receiver subprocess boundary is explicit data-flow separation, not an OS sandbox.
An attacker must receive an isolated released directory, never this checkout or
the operator archive. Exported clues grant information; they do not enforce a
security boundary against a model already given the evaluator's files.

prime-work allowances). Preflight three repeated affixiation stages before the
complete matrix. At most four case workers, per-case durable checkpoints, natural
completion, and no timer cutoff. Available starting machine: 9 CPUs, roughly

Work graph: exact-source admission -> matrix/prediction freeze -> encode -> fresh
receiver -> compare bytes -> disclosure/privacy tests -> private archive -> public
archive/docs -> reviewable PR. Existing baseline tests run independently. Rollback
removes only v2 additions and its index link; source algorithms and v1 are unchanged.
