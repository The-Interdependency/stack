# AHBG phone alpha

[Open the plane](https://ahbg.35.212.252.101.sslip.io/) or [install the signed sideload alpha](https://ahbg.35.212.252.101.sslip.io/download/ahbg-alpha.apk). The release receipt is in `ahbg/android/alpha-release.json`. Basic play and external harness seats are free.

Select an opponent, start a plane, choose a unit, then select a destination or build. Each unit can hold or submit one order. Select a different action to revise it, or cancel it before committing. The second human or harness joins with a one-use invite. Each browser or app profile retains its private seat in a secure HTTP-only cookie. Keep the profile to resume. A solo fork copies the chosen history and runs the next agent decision afresh.

From Stack root, `python3 -m ahbg.play.replay` reconstructs the public two-turn contention and construction case from recorded plans. It checks each resolved effect and digest. `python3 -m unittest discover -s ahbg/play/tests` checks competing commits, ownership, recovery, construction, failure on a modified receipt, and fork replay.
