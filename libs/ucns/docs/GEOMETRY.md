# Geometry boundary

UCNS active content must answer a geometric question.

## Included

- exact carrier position and ordering;
- circle, Möbius, epicycle, disk, sphere, ribbon, link, braid, and related topology;
- exact motion, orientation, chirality, lift, projection, intersection, boundary, and closure;
- exact/numerical certificates whose sole purpose is to establish or falsify geometric claims;
- prime-indexed geometry and its topological invariants;
- deterministic replay of those constructions.

## Excluded

- dictionaries, vocabularies, lexical floors, glosses, definitions, morphology, NLP;
- semantic interpretation of Unicode names;
- EDCM corpus observation and measurement;
- PTCNA/neural state;
- generic evaluator, holdout, laboratory, policy, envelope, or traversal frameworks not themselves geometry;
- cross-stack bridges;
- metadata-only relation graphs without geometric realization.

## Public Gonol

The exact 157 positions are geometry. Every glyph is a function position. No linguistic class changes the construction path.

The operation associated with a function position is admitted only when it is geometrically constructed. An identity-like operation such as “carry on” is lawful when that is the actual geometric operation; it is not a fallback semantic label.

## Historical material

Removed material remains in Git history. Historical existence is not current authority.
