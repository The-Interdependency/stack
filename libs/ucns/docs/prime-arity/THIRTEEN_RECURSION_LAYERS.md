# Thirteen Recursion Layers

Status: `INCUBATING` / `UNRESOLVED`

This document adds a thirteen-layer recursion map for the prime-arity experiment.

It is a calibration scaffold, not UCNS canon, not a theorem, and not a selected universal projection law.

## Boundary

The base arity carriers remain:

```text
2, 3, 5, 7
```

Thirteen layers are not thirteen roots. They are an inspection stack for testing whether base arity survives recursive load, projection, convergence, family-shadow, and zeta-shadow interpretation without collapsing into numerology.

## Why thirteen

`13` is useful because it is the first compact post-base calibration prime with all of these roles:

```text
13 is post-base relative to 2,3,5,7.
13 supports the 12 + 1 closure form.
13 has prime-prefix projection 13 = (2 + 3 + 5) + 3.
13 therefore carries base remainder 3 before the 7-boundary.
```

This makes thirteen a calibration gate, not a crown.

## Required preservation test

A candidate survives the thirteen-layer map only if each layer preserves the relevant distinction without replacing it by vocabulary:

| Layer | Required preservation |
|---:|---|
| 0 | Origin remains non-numeric. |
| 1 | Distinction remains prior to count/order. |
| 2 | Dyadic constraint is structural, not merely the numeral 2. |
| 3 | Triadic relation is structural, not merely the numeral 3. |
| 4 | Carry is explicitly defined and replayable. |
| 5 | Closure/readout is measured, not assumed. |
| 6 | Composite-family shadow stays distinct from arity offspring. |
| 7 | Heptadic boundary does not replace the base set. |
| 8 | Projection declares what it preserves and collapses. |
| 9 | Cardinal collision preserves exact contributing paths/loads. |
| 10 | Multiplicity of convergence remains an evidence object. |
| 11 | Twin coupling is compared against non-twin controls. |
| 12 | Zeta-family ledger remains finite Euler-product context, not a zeta-zero claim. |
| 13 | Epoch capture remains a candidate until falsifiers/replay pass. |

## Failure conditions

The thirteen-layer map fails if:

```text
13 is treated as a new root arity.
The map is used as proof rather than a scaffold.
Any layer is renamed after seeing desired outputs.
Projection law Π remains implicit while claims are made from results.
Zeta-family context is promoted to a zeta-zero explanation.
Twin coupling is not checked against matched non-twin controls.
```
